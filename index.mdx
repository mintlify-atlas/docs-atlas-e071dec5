Akam Token (AKAM) is a minimal, immutable ERC-20 smart contract deployed on the Polygon PoS network. With a hard-capped supply of 400,000,000 AKAM minted at construction and no owner or admin functions, the token is fully decentralized and requires no ongoing governance. It is built with OpenZeppelin's audited ERC-20 implementation and developed using the Foundry toolchain.

## Quick overview

<Steps>
  <Step title="Clone and install dependencies">
    ```bash
    git clone https://github.com/Elvatar2/Akam-Token.git
    cd Akam-Token
    forge install
    ```
  </Step>
  <Step title="Build the contract">
    ```bash
    forge build
    ```
  </Step>
  <Step title="Run the test suite">
    ```bash
    forge test
    ```
  </Step>
  <Step title="Integrate">
    Import the ABI and use the standard ERC-20 interface to transfer tokens, approve spenders, and query balances from any Solidity contract or off-chain client.
  </Step>
</Steps>

<Note>
  AKAM has a **fixed supply**. There is no `mint` function and no privileged owner — once deployed, the total supply of 400,000,000 AKAM can never change.
</Note>
